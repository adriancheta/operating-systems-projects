# Operating Systems Laboratory Projects

A collection of three C projects completed as part of my
Operating Systems laboratory coursework at the Technical
University of Cluj-Napoca.

The projects explore file-system operations, process and
thread synchronization, and inter-process communication
in Linux.

## Projects

### 1. File System Module
A command-line utility for directory traversal, binary
file-format parsing, validation, and data extraction.

[View project](./a1-file-system/)

### 2. Processes and Threads
A Linux program demonstrating process creation,
multithreading, and synchronization.

[View project](./a2-processes-threads/)

### 3. Inter-Process Communication
A program using named pipes, shared memory, and
memory-mapped files to handle communication and
file-data access.

[View project](./a3-inter-process-communication/)

## Technologies

- C
- Linux and POSIX system interfaces
- File handling and binary data parsing
- Processes, threads, and synchronization
- Named pipes, shared memory, and memory mapping
